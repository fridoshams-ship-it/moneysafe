# MoneySafe

Сейф от самого себя: крипта блокируется до выбранной даты и приносит доход в Aave V3 или Compound III, пока ждёт.
Досрочного вывода нет ни у кого — ни у владельца, ни у MoneySafe.

## Состав

| Папка | Что внутри |
|---|---|
| `contracts/` | Смарт-контракты (Solidity, Hardhat): фабрика сейфов, сейф, Aave V3 + Compound III, сети Polygon и Arbitrum, тестовый рынок для беты. `npm test` — 25 тестов. Отчёт пред-аудита — `contracts/AUDIT-PRELIM.md`. |
| `web/` | Веб-приложение: демо-режим и режим тестовой сети (viem + Reown AppKit: WalletConnect, вход Google / Apple / email). `npm run build`. |
| `.github/workflows/` | CI: тесты контрактов при каждом изменении, развёртывание тестовой сети по кнопке, публикация веб-приложения на GitHub Pages. |

## Газ за пользователя (Pimlico)
Если добавить секрет `PIMLICO_KEY` (Settings → Secrets and variables → Actions), сайт и приложения собираются с оплатой газа: адрес пользователя в MoneySafe становится смарт-счётом (ERC-4337, SimpleAccount v0.7), которым управляет его кошелёк, а газ платит paymaster Pimlico. Кошелёк только подписывает действия, ETH на газ не нужен.
В панели Pimlico задайте политику спонсорства (лимит в день и разрешённые адреса контрактов: фабрика MoneySafe, токены) — ключ виден в коде сайта.
Проверено локально (`web/test/aa`): свой бандлер и verifying paymaster вместо Pimlico; кошелёк с нулём ETH создаёт сейф и бюджет, досрочный вывод отклоняется.

## Деньги на каждый день
Второй вид сейфа: кладёте сумму (например, 200 USDC) и часть на день или неделю (20 USDC). Каждый период открывается только своя часть, неиспользованное копится. Увеличить часть — раз в 30 дней, уменьшить — в любой момент, со следующего периода. Контракт `MoneySafeAllowance`, создаётся фабрикой (`createAllowance`).

## Бета на реальных деньгах (Arbitrum One и Base)
Контракты ещё без независимого аудита, поэтому в одном сейфе — не больше бета-лимита (`betaCap` в `contracts/config/networks.json`: 500 USDC / 500 USDT / 0,2 ETH / 0,006 WBTC).
1. Создайте **новый** кошелёк только для развёртывания, положите на него ~$3–5 в ETH в сети Arbitrum.
2. Settings → Secrets and variables → Actions → Secrets: `MAINNET_DEPLOYER_KEY` = приватный ключ этого кошелька.
3. Actions → «Deploy mainnet (real money, beta)» → Run workflow → выберите сеть (arbitrum или base) → в поле confirm напишите `DEPLOY`. Для Base кошельку нужен ETH в сети Base. Сначала прогонятся все тесты и тест на копии настоящей сети, потом развёртывание; адреса сохранятся в `contracts/deployments/arbitrum.json`, и сайт пересоберётся сам.
4. На сайте выберите «Реальные деньги». Кошелёк: откройте сайт во встроенном браузере MetaMask / Trust Wallet (кнопки есть на экране входа) или задайте `REOWN_PROJECT_ID` для WalletConnect.
ETH кладётся в сейф как WETH (приложение само обернёт и при выводе развернёт обратно в ETH).

## Запуск тестовой сети

1. Создайте новый кошелёк только для тестов и получите на него тестовый ETH в сети Arbitrum Sepolia.
2. В репозитории: Settings → Secrets and variables → Actions → добавьте `DEPLOYER_KEY` (ключ этого кошелька) и `ARB_SEPOLIA_RPC` (адрес RPC, например от Alchemy).
3. Actions → «Deploy testnet» → Run workflow. Адреса контрактов сохранятся в `contracts/deployments/`.
4. Веб-приложение пересоберётся само и появится переключатель «Тестовая сеть».

Демо-режим: деньги, монеты и блокчейн ненастоящие, код для входа по email — `2486`.
Тестовая сеть: настоящий блокчейн, токены без ценности. Перед основной сетью обязателен независимый аудит.
